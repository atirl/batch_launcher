# ファイル起動くん
バッチ、pythonなどを監査付きで起動するランチャー
バッチなどを起動した時間がログに記録されるので、業務などで手動で起動するファイルがある人向けです。
あえて「10フォルダまで、75ファイルまで」という制限を設けているのは、そもそもそんなに手動起動するなという戒めのためです。

## 1. 概要

-   指定したフォルダ直下から、起動対象のファイルを取得します。
-   複数のフォルダを登録し、ファイル一覧をまとめて表示できます。
-   ファイルの起動前に確認ダイアログを表示します。
-   起動操作、フォルダ追加、キャンセルなどを含めログファイルに記録します。

## 2. 動作環境

-   OS： Windows
-   制作言語： Python
-   GUI： Tkinter
-   外部ライブラリ： 不要
-   実行方法： Pythonスクリプトとして実行、またはEXE化して実行
-   設定ファイル： 本体と同じフォルダに target_folder.txt
    を配置します。ファイルがない場合は、既定の 実行対象
    フォルダを使用します。

起動対象の拡張子

  拡張子   起動方法
  -------- ---------------------------------
  .bat     cmd.exe から実行
  .exe     直接実行
  .vbs     wscript.exe から実行
  .lnk     Windowsの関連付けを利用して起動
  .py      python コマンドで実行

※ .py ファイルの起動には、Windows上で pythonコマンドを実行できる環境が必要です。無理な場合はexeファイルを使ってください。

## 3. ファイル構成

アプリケーションの配置例です。

    ファイル起動くん/
    ├─ FileKidoukun.py             # 本体
    ├─ target_folder.txt       # 対象フォルダ設定。勝手に作られます。
    ├─ kidoukun_log.txt        # 実行ログ。勝手に作られます。
    └─ 実行対象/                # 初期状態で指定されているフォルダ。なくても良かったかも

-   FileKidoukun.py：アプリケーション本体。ファイル名は変えてもいいです。
-   target_folder.txt：登録した対象フォルダのパスを保存します（10フォルダまで）
-   kidoukun_log.txt：起動、操作、ファイル実行、エラーなどのログを記録します。
-   実行対象：設定ファイルがない場合に使用する既定のフォルダ。

## 4. 使い方

① 起動

Pythonスクリプトとして実行する場合は、コマンドプロンプトなどから起動します。

    python kidoukun.py

EXE化した場合は、作成した実行ファイルを起動します。

② メイン画面

起動すると、登録した対象フォルダ内にある対象ファイルがボタンとして表示されます。

-   対象設定： ファイルを取得するフォルダを追加・削除します。
-   再読込： 登録フォルダを再確認し、対象ファイル一覧を更新します。
-   実行ログ： ログファイルをメモ帳で開きます。
-   終了： アプリケーションを終了します。

ファイルのボタンを押すと、起動確認ダイアログが表示されます。「はい」を選ぶとファイルを起動し、「いいえ」を選ぶと起動をキャンセルします。

③ 対象フォルダの設定

1.  メイン画面の「対象設定」を押します。
2.  「フォルダ追加」で登録するフォルダを選択します。
3.  不要なフォルダは一覧から選択し、「選択フォルダ削除」を押します。
4.  「設定」を押すと設定を保存し、メイン画面を再読み込みします。
5.  変更を取り消す場合は「キャンセル」を押します。

-   登録できるフォルダは最大10個です。
-   1個以上のフォルダを登録する必要があります。
-   存在しないフォルダが含まれている場合は、確認ダイアログが表示されます。
-   フォルダ設定は target_folder.txt に保存されます。

④ 再読込

「再読込」を押すと、登録済みフォルダから対象ファイルを取得し直し、ボタン一覧を更新します。
対象フォルダにファイルを追加・削除した場合などに使用します。

⑤ ファイル数の上限

-   表示できるファイル数は最大75個です。
-   最大15行×5列の配置を想定しています（元々10個×2列の20個でしたが公開にあたり増やしています）
-   対象ファイルが75個を超えた場合は警告を表示し、ファイル名順の先頭75個を表示し、超過分は表示しません。
-   フォルダ内のサブフォルダは検索しません。
-   対象ファイルはファイル名順に並びます。同名の場合はフォルダパス順です。

## 5. target_folder.txt について

テキストファイルからも編集できますが、アプリケーションの「対象設定」ボタンから設定すれば設定日時などがログに記録されるので、そちらをおススメします。

## 6. ログ

ログはアプリケーションと同じフォルダの kidoukun_log.txt に追記されます。

主に次の内容を記録します。

-   アプリケーションの起動・終了
-   ボタン操作
-   ファイルの起動成功・失敗
-   対象フォルダの読み込み・設定保存に関するエラー
-   対象ファイル数が表示上限を超えた場合の警告

メイン画面の「実行ログ」ボタンを押すと、ログファイルをメモ帳で開きます。

## 7. 起動時の動作

1.  アプリケーションの起動ログを記録します。
2.  target_folder.txt から対象フォルダを読み込みます。
3.  登録フォルダがすべて存在しない場合は、対象フォルダを指定するか確認します。
4.  登録フォルダ直下から対象ファイルを取得します。
5.  ファイル数を確認し、必要に応じて上限超過の警告を表示します。
6.  対象ファイルのボタンをメイン画面に表示します。

対象フォルダがすべて見つからず、フォルダ指定を行わない場合はアプリケーションを終了します。対象フォルダの読み込み自体に失敗した場合も、起動を中止します。

## 8. 補足

-   .py は pythonコマンドで起動するため、環境に依存します。
-   ログの書き込みに失敗した場合、ログ書き込み関数は例外を無視するため、ログが残らないことがあります。
-   ファイルの実行に必要な権限、関連ソフトウェア、実行環境は別途用意してください。
